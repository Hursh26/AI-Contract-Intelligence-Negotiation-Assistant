# AI Contract Intelligence & Negotiation Assistant

An AI-powered system that helps users **understand, compare, question, and negotiate** legal or business contracts — going beyond simple summarization into interactive contract analysis and negotiation support.

## Overview

Traditional contract tools stop at summarization. This project aims to:
- **Understand**: Break down complex legal/business language into plain terms
- **Compare**: Diff clauses across contract versions or against standard templates
- **Question**: Let users ask natural-language questions about specific clauses or risks
- **Negotiate**: Suggest redlines, alternative clause language, and negotiation strategy based on context
